Arquitectura de componentes

Descomposición técnica del plan Intermedia Plus del asistente de gestión agrícola: un front-end de WhatsApp sobre las APIs de CENICAÑA, un RAG básico sobre la documentación de manejo agronómico y una capa de ponderación de contexto antes de redactar, como un solo servicio Python sobre PostgreSQL 16.

01

Arquitectura

Un solo contenedor Python (FastAPI + LangGraph) sobre el PostgreSQL que CENICAÑA ya opera. El webhook de WhatsApp entra por HTTPS a través del WAF; las llamadas a las APIs de CENICAÑA salen por la red interna (VPN / IP en allowlist); Claude y Whisper se alcanzan por firewall/WAF saliente. En este plan el canal es solo WhatsApp.

servicio propio almacén componente sistema externo
02

Componentes del Servicio del Asistente

El servicio se organiza en cinco capas. El borde recibe el mensaje de WhatsApp y transcribe la voz; el núcleo orquesta el turno con LangGraph; las acciones consultan la API de CENICAÑA o el corpus y ponderan lo recuperado; el apoyo hace el trabajo transversal y la analítica de afinamiento; los repositorios hablan con PostgreSQL. El AgentGraph es el único que decide qué acción ejecutar; nunca toca la base de datos directamente.

06

Fuera de este plan

El plan Intermedia Plus no incluye estos componentes, que son el salto al plan Full:

  • IntegrationHook · ChannelKeyRepository — conector de integración a Telegram y a la web (API HTTP con clave de canal)
  • ResponseCache — caché de corta duración sobre respuestas de la API
  • SoilAnalysisInterpreter · DocumentExtractor + tabla de rangos — interpretación de un documento adjunto (por ejemplo, un análisis de laboratorio)
  • Pruebas de carga formales y evaluación de calidad con set de preguntas doradas

Sin rehacer nada. El núcleo neutral al canal (grafo, ConversationService, CheckpointStore, repositorios) y el ContextRanker quedan listos para recibir estos componentes en una fase posterior. El conector se enchufa al mismo núcleo; la caché se intercala en CenicanaApiClient; la interpretación de adjuntos entra como una intención más del router.
